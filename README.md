# Bangumi

这是 [Bangumi](https://github.com/xiaoyvyv/bangumi) 的 **Miuix / HyperOS** 风格衍生版，包名为 `com.kifranei.bgm.miuix`。

上游原项目是 [xiaoyvyv/bangumi](https://github.com/xiaoyvyv/bangumi) 的 Compose Multiplatform 分支。本仓库在此基础上把界面改成 Miuix 组件，并加入自定义主题色、可选液态玻璃底栏等。自用

许可证为 [GPL-3.0](LICENSE)

- 上游：https://github.com/xiaoyvyv/bangumi/tree/multiplatform
- UI：[Miuix](https://github.com/compose-miuix-ui/miuix)
